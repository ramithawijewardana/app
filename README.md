The **Nestify App** is the main mobile-friendly platform for residents.  
It connects residents with the community through **facility booking, billing, requests, and voting**.

## 🚀 Features
- Resident dashboard with personalized access.  
- Book facilities (gym, pool, hall, etc.).  
- View and pay bills.  
- Submit and track requests.  
- Vote in community polls.  
- Receive push/email/SMS notifications.  

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript (Mobile-first design with Tailwind)  
- **Backend:** Firebase Authentication + Firestore Database  
- **Deployment:** Vercel / Firebase Hosting  
- **Future:** React Native / Flutter (for mobile apps)
